# 5\. Project Communications

| **Communication Item** | **Who/ Target** | **Purpose** | **When, Frequency** | **Type, Tool, Method(s)** |
| --- | --- | --- | --- | --- |
| Weekly Planning Meeting | All team members | Plan tasks for upcoming week, assign Jira user stories, discuss technical blockers (AST, LLM, Kafka) | Every Thursday, 1 session/week | Meet to meet |
| Weekly Progress Review | All team members + Project Advisor | Share progress, review SRS/PMP alignment, adjust 10-week timeline | Every Friday, 1 session/week | Meet to meet |
| Internal Feature Demo | Relevant developers + Reviewer | Validate completed features (e.g., AST Drift Engine, Visual Diff Viewer, PR Bot) before merging | After each feature completion | Live screen share via Zalo or pre-recorded Loom video |
| Documentation Review | 2 assigned members (QA/BA + Lead) | Review and update SRS, SDD, Test Cases, and User Manual | Every 2 weeks | Google Docs / Confluence comments + revision history |
| Code Review Session | Feature developer + Reviewer | Review logic, Spring Boot/FastAPI structure, Tree-sitter AST conventions, and test coverage (\>= 80%) | Before merge to main branch | GitHub Pull Request + discussion via comment |
| Urgent Bug or Blocker Sync | Involved members only  | Quickly resolve urgent issues (API breakages, Kafka/Redis pipeline failures, Docker deployment errors) | Ad-hoc | Zalo chat/call or Discord voice |
| Final Demo Rehearsal | All members | Full demo run-through (end-to-end PR drift flow), time-check, Q&A preparation for final defense | Week 9 – Week 10 (Before presentation) | In-person meeting |
| Shared Asset Management | All members | Collaborate on Figma UI designs, architecture diagrams, project docs, and presentation slides | Continuous | Google Drive & Figma |
