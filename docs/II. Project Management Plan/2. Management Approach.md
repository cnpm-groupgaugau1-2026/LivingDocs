# 2\. Management Approach

### 2.1 Project Process

- The project applies the **Agile Scrum** methodology.
- **Iteration model:** 2-week sprints, total of 4 sprints (8 weeks).
- **Phases:**
    - **Sprint 1:** Requirement elicitation, system architecture & database design, System Foundation, Workspace & Dynamic Templates (FE01, FE11, FE13).
    - **Sprint 2:** Core AI Engine, AST Code Parsing, Drift Classifier & Multimodal Vision-LLM (FE02, FE04, FE05).
    - **Sprint 3:** Event-triggered Auto-update Workflow, GitHub Actions CI/CD, Governed 2-Tier Approval & Interactive Diff Viewer (FE03, FE06, FE07, FE09).
    - **Sprint 4:** Role-Attributed Audit Trail, Health Analytics Dashboard, Hybrid RAG Search (FE08, FE10, FE12), System Testing, UAT, and Deployment.
- **Scrum ceremonies:** Daily stand-up (15 minutes), Sprint Planning, Sprint Review, and Sprint Retrospective.
- **Artefacts:** Product Backlog, Sprint Backlog, Burndown Chart, Increment.

### 2.2 Quality Management

         The quality objective is to ensure a stable, accurate, maintainable system with high user satisfaction.

The approach includes:

- **Defect Prevention:**
    - Enforce coding standards and best practices (ESLint/Prettier for Frontend, Checkstyle for Spring Boot, Flake8 for FastAPI).
    - Database normalization, PGVector indexing, and foreign key constraints to minimize data errors and inconsistency.
- **Reviewing:**
    - Mandatory code review with at least 2 reviewers before merging code into `develop` or `main` branches.
    - Peer review for project documents (SRS, Architecture Design, DB Schema, API Specifications, Test Cases).
- **Unit Testing:**
    - Tools: Jest / React Testing Library (Frontend), JUnit 5 / Mockito (Spring Boot Backend), PyTest (FastAPI AI Engine).
    - Goal: \>= 80% code coverage, covering AST code parsing functions, API endpoints, and core business logic.
- **Integration Testing:**
    - Tools: Postman / Newman for API workflows, Kafka event queue processing, and Redis caching handling.
    - Integration testing for GitHub OAuth/Webhooks, OpenAI / Vision-LLM API, and Jira integration workflows.
- **System Testing:**
    - Conducted on a staging environment hosted on Cloud infrastructure (Docker Compose / AWS EC2).
    - Full regression testing of all major features (FE01–FE13).
    - SLA & Performance testing (e.g., Locust / JMeter) to verify documentation drift detection in \<2 minutes for 100k LOC.
- **Acceptance Testing:**
    - User Acceptance Testing (UAT) with project stakeholders (Project Advisors, Developers, Staff Reviewers, Managers).
    - Ensure 100% of critical features pass before go-live.
