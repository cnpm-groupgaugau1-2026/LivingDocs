### 1.3 Project Risks

| **#** | **Risk Description** | **Impact** | **Possibility** | **Response Plans** |
| --- | --- | --- | --- | --- |
| 1 | AI LLM Hallucination & False Positive Drift Detection | High | Medium | Enforce AST grounding evidence; 2-tier review workflow (Staff/Manager sign-off); prompt optimization & threshold tuning. |
| 2 | 3rd-Party Integrations & API Limitations (GitHub OAuth/Webhooks, OpenAI, Jira) | Medium | Medium | Early POC in sandbox; Kafka event buffering; exponential backoff retries & Redis response caching. |
| 3 | Processing Latency SLA Violation on Large Repos (\>100k LOC or complex diagrams) | High | Medium | Async worker queue processing (Kafka/FastAPI); Tree-sitter AST parsing optimization; hybrid OCR/Vision-LLM fallback. |
| 4 | Data Privacy & Codebase Exposure Security Concerns | High | Low | Data anonymization/masking before LLM ingestion; RBAC; encrypted API keys at rest/in-transit; audit logging. |
| 5 | LLM Token Budget & API Cost Overruns | Medium | Medium | Token consumption tracking & caps per workspace; PGVector embedding caching; hybrid local LLM (Ollama) routing. |
| 6 | Scope Creep & Schedule Slippage (2-Month Timeline Constraint) | High | Medium | Strict WBS baseline freezing; 4-phase milestone tracking; feature prioritization (MVP first); weekly advisor sync. |
| 7 | AST Parser Edge-Case Limitations on Complex/Unusual Syntax | Medium | Medium | Fallback to regex & structural keyword search; set supported language boundaries (Java, Python, TypeScript); safe error handling. |
| 8 | Resource Availability & Technical Skill Gap in Microservices/AI Pipelines | Medium | Medium | Cross-training between Spring Boot & FastAPI; pair programming; clear component ownership; daily standups & buffer days. |
